FAQ

Questions Jira administrators ask before trying Resultary.

Short answers to the product, security and beta questions that matter most.

Does Resultary replace Jira Automation?

No. Resultary sits beside important Jira automations as an assurance layer. Jira Automation performs the work; Resultary checks the protected run signal and configured Jira business evidence.

Does Resultary modify my Jira Automation rules?

No. Resultary does not edit, enable, disable or delete Jira Automation rules.

What is the difference between a run and a verified result?

A run signal says the protected automation reached the point where it sent its Resultary heartbeat. A verified result means Resultary also found the configured Jira evidence that represents business success.

What happens if an automation runs successfully but the expected Jira result is missing?

Resultary keeps the run and business-result signals separate. A successful run can remain healthy while the business-result check enters confirmation and, if the failure persists, becomes an actionable incident.

Why confirm a failure before opening an incident?

Confirmation reduces noise from one-off timing or consistency effects. Persistent failure can then create one actionable incident instead of duplicate alerts.

Where is app data stored?

Core Resultary app state uses Atlassian Forge-hosted storage. Optional Slack or Teams notifications send selected alert information to the administrator-configured external endpoint.

Does Resultary support data residency?

Forge-hosted persistent storage inherits Atlassian Forge data-residency capabilities. See the Trust and Privacy pages for the current description and Atlassian documentation link.

Does Resultary guarantee financial savings?

No. Business-value metrics are estimates based on administrator-configured values and verified recovery. They help prioritize and communicate exposure; they are not accounting statements or guarantees.

How does the beta work?

The beta is a free 30-day evaluation for Jira Cloud. No payment is required. You can install Resultary directly and receive founder support for setup, configuration, testing and product questions throughout the evaluation.

Is Resultary available for purchase now?

Not yet. Resultary is currently being validated through the beta. Commercial packaging and pricing will be finalized after beta feedback.
