What to include in a support request

Context

Jira site name, monitor name and whether the issue is setup, verification, incident, notification or recovery related.

Timing

Approximate date/time and timezone of the run or error so the relevant event can be identified.

Safe evidence

Visible error text or a screenshot with secrets removed.

Never send: passwords, Atlassian tokens, protected heartbeat URLs, Slack webhook URLs, Teams webhook URLs or other credentials.

Beta support level

Support is available throughout the 30-day evaluation and is handled personally on a best-effort basis. There is no contractual 24/7 response-time, uptime or recovery SLA during beta unless separately agreed in writing.
