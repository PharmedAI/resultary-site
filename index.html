The problem

A green automation log can still hide a business failure.

Execution status answers “did the rule run?” Resultary adds the second question that matters: “did the intended Jira outcome actually happen?”

Level 1 · Run assurance
✓ Successful run

The rule reached its run path and sent its Resultary signal.

Level 2 · Business-result assurance
! Outcome missing

The expected field change, ticket, status or matching Jira evidence is not there. Resultary keeps the two signals separate.
